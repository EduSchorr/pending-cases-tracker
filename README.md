## About

Tracks operational pending cases and structures follow-up communications and exports.

This repository is a **sanitized portfolio edition** of an operational project. Production customer data, credentials, private endpoints, workstation-specific paths and runtime databases are intentionally excluded.

## What it demonstrates

- Excel base import;
- case processing and categorization;
- WhatsApp queue workflows;
- contact and hierarchy management;
- dashboards, logs and exports;
